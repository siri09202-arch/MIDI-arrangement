# MIDI-arrangement

ブラウザで動作する **AI MIDI Arranger** の実装です。

## 機能

- MIDIファイルのアップロードと解析
- ジャンル自由指定
- 本格的なアレンジ／フル編成／原曲BPM維持を既定設定
- 原曲メロディー維持・楽器パート割り当ての指示を既定設定
- トラック数・ノート数・演奏長・テンポの表示
- アレンジ後のMIDIダウンロード

> 現在のアレンジ処理はブラウザ上のデモ実装です。本格的なAI生成には外部API連携が必要です。

## 開発

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```
